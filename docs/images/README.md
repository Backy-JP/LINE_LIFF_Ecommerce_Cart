# 圖片資料夾

此資料夾用於存放 README 文件中的截圖。

## 需要的截圖

請將以下截圖放入此資料夾：

1. **line-richmenu.png** - LINE 聊天室與圖文選單界面
2. **product-page.png** - 商品展示頁面（Pei Shop 首頁）
3. **cart-page.png** - 購物車頁面

## 截圖規格建議

- 格式：PNG（推薦）或 JPG
- 寬度：建議 750-1500px（手機截圖原始尺寸即可）
- 檔案大小：建議 < 500KB（可使用壓縮工具優化）

## 壓縮工具推薦

- [TinyPNG](https://tinypng.com/) - 線上 PNG/JPG 壓縮
- [ImageOptim](https://imageoptim.com/) - Mac 專用壓縮工具
